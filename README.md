# Assignment 4 — Heap Data Structures

This project implements in-place Heapsort, compares three sorting algorithms, and uses a heap-based priority queue to schedule tasks.

## Run the project

From this directory, run the following commands with Python 3. No third-party packages are required.

```bash
python3 heapsort.py
python3 sorting_benchmark.py
python3 priority_queue.py
python3 scheduler_simulation.py
```

## Results

Merge Sort had the lowest median time in eight of nine cases in the reported benchmark. The scheduler ran five tasks with an average wait of 2.60 time units and one missed deadline.
